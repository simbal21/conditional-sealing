# Historical deployment files — not deployable

The Railway and Docker files in this folder (`railway.toml`, `Dockerfile.railway`,
`build-railway.sh`, `PHASE-G-LIVE-DEPLOY-RUNBOOK.md`, `phase-g-preflight.sh`) record how the G4
Phase 1 daemon was meant to be deployed for a pilot. That pilot never ran in production, and the
hosting project they targeted was deleted after the project was retired in June 2026.

They are kept as a record of the intended operational design. There is no live service behind
them, and running them will not connect to anything that exists.
