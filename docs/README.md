## A note on internal citations

These documents were working artifacts of a real build. They occasionally cite
internal materials that are **deliberately not part of this export** — internal
rulebooks ("Rule 26", "Table B"), build briefs, closure documents, agent working
notes, and a handful of design records (e.g. `dek-lifecycle.md`,
`conditional-recipient.md`). Those citations were left in place as honest
provenance rather than rewritten. Where a cited document has a public
equivalent in this repo, the path points at it; where it doesn't, the reference
is annotated or names the document without a path.

Everything here is published as a **point-in-time record** of a retired project
(June 2026). These documents also predate the release-naming decision: where a
research document says the public release name was undecided, the name later
chosen is **conditional-sealing** (see the naming note in the root `README.md`).
See the root `README.md` and `SECURITY.md` for what this project is — and,
more importantly, what it is not.
